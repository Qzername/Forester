# Proces aktulizacji Forestera

1. zamieniasz nazwe exe z Forester.Desktop.exe na Forester.exe reszte nie musisz
2. usuwasz dla bezpieczenstwa trzy pliki: checksum.json, version.json, settings.json
3. zipujesz wszystkie rzeczy w foldezre z foresterem ale nie sam folder
4. wchodzisz do postmana i pod zapytanie: http://***REMOVED***:5000/Update/Upload?version=version gdzie version to twoja wersja dajesz do forma key file zipa
5. przesylasz i masz
