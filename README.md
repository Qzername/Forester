# Forester
A project made so you can send and update files faster and more plesantly, without need of git

> [!NOTE]
> The next version (that is v3.3.0) will be substantially easier to run and use

### How to use:

- Compile the server project and run it
- Go to Forester/Data/Connection/Manager.cs and change the BaseAddress to your server ip address
- Compile the project

### How to gain access to developer panel:

If you want to release applications, you need to gain access to developer panel, currently the only option is to modify IsDeveloper value in database.db in ForesterServer. After modificaiton, run the client and you will see additional window called "Developer".
